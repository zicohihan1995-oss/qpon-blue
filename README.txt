【重要】
このフォルダは新版専用です。現在公開中の安定版Netlifyサイトへは上書きせず、Netlifyの「Add new project」で新規サイトとして公開してください。

【再生操作】
・再生中の同じQをもう一度押すと、そのQだけ即停止します。
・異なるQは、すでに鳴っている音を止めずに同時再生します。
・FI設定中のQも、再押下時はフェードを待たず即停止します。
・MASTER FOの横で1/2/3/5/10秒を選択できます。「任意」では0.1〜30秒を入力できます。
・FO時間、マスター音量、Q別音量、FI設定はこの端末に保存されます。

【公開】
このフォルダを丸ごとNetlify Drop等へドラッグ＆ドロップしてください。
HTTPSで公開するとPWA・オフライン保存が利用できます。

【操作】
- Qボタン：そのQを再生。すでに鳴っている音は止まりません。
- MASTER FO：再生中の全音を設定秒数でまとめてフェードアウトして停止。
- STOP：全音を即停止。
- Q設定：個別音量、FIのON/OFF、FI秒数を設定。端末内に自動保存。

本番ではiPadの自動ロック、通知、着信を無効化し、電源接続を推奨します。
